```bash
# 2. Run simulation (requires Java)
.\scripts\run_amlsim.bat

# 3. Copy output to this directory
copy outputs\*.csv "D:\OneDrive\Desktop\Finance Fraud\data\amlsim\"
```

## Data Schema

### accounts.csv
- account_id: Unique account identifier
- init_balance: Starting balance
- country: Account country code
- business_type: I (Individual), C (Corporate)
- is_sar: Suspicious Activity Report flag

### transactions.csv
- tx_id: Transaction ID
- timestamp: Transaction time
- orig_id: Sender account (FROM)
- dest_id: Receiver account (TO)
- tx_amount: Amount transferred
- is_sar: Part of suspicious pattern

### alert_accounts.csv
- account_id: Account ID
- alert_type: fan-out, fan-in, cycle, scatter-gather, bipartite
- sar_flag: SAR filing flag
- schedule_id: Pattern schedule reference

## Usage in Project

After data is placed here, run:
```bash
python build_amlsim_graph.py
```

This will:

2. Build transaction network graph
3. Detect money laundering patterns
